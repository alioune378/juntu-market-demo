# Juntu African Market — e-commerce demo
Designed & developed by Dalal Technologies.

This is a static site with no build step and no dependencies. Open `index.html` through any static host (Netlify: publish directory `/`).

- `index.html`, `styles.css`, `app.js`: the storefront (hash routes such as `#shop`, `#p-juntu-thiakry`, `#cart`, `#checkout`)
- `config.js`: demo mode, store facts, WhatsApp/hours toggles, shipping on/off. **Start here before launch.**
- `data.js`: the catalog (provisional prices, search aliases, shipping eligibility)
- `assets/`: optimized WebP product photos (Juntu's own + `list/` staples), the real store photos (`store/`) and the logo
- `docs/`: handover guide, Shopify import CSV, catalog verification checklist

See `docs/OWNER-APPROVALS.md` for everything that still needs the owner's sign-off, and `docs/HANDOVER.md` for demo vs. production, the Shopify/FedEx/pickup setup, the owner guide and the launch checklist.
